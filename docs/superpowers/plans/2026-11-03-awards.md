# Awards + Certificates Plan

**Goal:** 比赛结束后按名次自动生成金/银/铜奖；管理员可配置比例；生成可打印证书与奖项成绩单 CSV。

**Decisions：**
- 默认比例：金 10%、银 20%、铜 30%（按正式榜人数，累计名次）。
- 并列名次同奖；可能略超比例。
- 只统计正式榜（official ranking）；hidden 选手不参与。
- 奖项默认按个人榜；团队比赛可后续扩展团队奖，本轮先个人。
- 证书为浏览器打印页（HTML/CSS），不引入 PDF 依赖。
- 奖项在比赛结束后才公开；管理员可随时预览。

## Global Constraints

- 不新增依赖。
- 旧比赛 `award_config_json` 默认 `{}`，使用默认比例。
- 不改排名/计分。
- 管理员配置写审计。
- 证书只展示用户名/姓名/学校/班级/名次/奖项/比赛名，不泄露联系方式。

Interfaces:
```ts
export interface AwardConfig { goldPercent: number; silverPercent: number; bronzePercent: number }
export interface AwardRow {
  rank: number; userId: number; username: string; realName: string|null; className: string|null;
  totalScore: number; solved: number; award: 'gold'|'silver'|'bronze'|null;
  certificateNo: string;
}
export function getAwardConfig(contest): AwardConfig
export function setAwardConfig(db, contestId, config): void
export function getContestAwards(db, contestId): { contest; config; rows; counts }
```
Rules:
- percent numbers 0..100, sum <=100 (allow 0); integers? allow decimals, round counts.
- counts: gold=Math.round(n*gold/100), silver=..., bronze=...; at least 1 for non-zero percent when n>0? Decide and test. Recommended: `Math.max(1, Math.round(...))` if percent>0, capped at n; cumulative may exceed n -> cap.
- rank <= cumulative thresholds; ties keep award.
- rows with rank after bronze -> award null (still included? API returns all official rows with award; UI filters).
- certificateNo: `contestId-{userId}` or `C{contestId}-{rank}`; stable.
- Only archived/ended? API can return; HTTP enforces admin or contest ended.
- `GET /api/contests/:id/awards` auth; if contest not ended and not admin/manager -> 403 AWARDS_NOT_READY.
- `GET /api/admin/contests/:id/awards`
- `PUT /api/admin/contests/:id/awards/config` body config; admin/contestmanager; audit.
- `GET /api/contests/:id/awards.csv` optional? Can be frontend CSV; skip backend.

Tests: config default/validation, counts/ties, hidden excluded, ended gate, admin config, certificateNo stable.
