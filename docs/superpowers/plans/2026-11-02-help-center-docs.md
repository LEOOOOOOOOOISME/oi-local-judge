# Help Center Docs System Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development or superpowers:executing-plans.

**Goal:** 把 `docs/help` 从“仓库里的 Markdown”变成应用内可浏览、可搜索、可深链的帮助中心。

**Architecture:** 构建期把 Markdown 预渲染为 `generated-help.ts`（HTML 已 sanitize），前端只做加载/搜索/路由，不在浏览器引入 Markdown/KaTeX 运行时。搜索是纯函数，按标题/分类/正文匹配。

**Tech Stack:** Node 24、markdown-it、markdown-it-texmath、katex、sanitize-html、React 18、AntD 5、Vitest。

**Spec:** `docs/superpowers/specs/2026-11-02-oi-judge-v0.3-requirements.md` 第 4 节。

## Global Constraints

- 不新增依赖：`markdown-it`、`markdown-it-texmath`、`katex`、`sanitize-html` 已在根 package。
- 生成文件 `apps/web/src/help/generated-help.ts` 必须提交；`npm run build` 前重新生成。
- 文档链接中的相对 `.md` 必须重写为 `/help?doc=<slug>`；外部链接保留。
- 不复制 GPL/AGPL 内容；只读 `docs/help/**/*.md`、`docs/ranking.md`、`docs/batch-import.md`。
- 帮助中心完全离线；不请求外网。

- Category mapping: `getting-started` → `开始`; `authoring` → `出题`; `contest` → `比赛`; `judging` → `评测`; `team` → `团队`; `system` → `系统`; `faq` → `FAQ`; default `开始`.
- Title: first `# ` line; fallback slug.
- Markdown render:
  - `markdown-it({html:false,linkify:true,typographer:false})`
  - `.use(texmath, {engine:katex, delimiters:'dollars', katexOptions:{throwOnError:false}})`
  - heading_open rule: id = lower-case text, spaces→`-`, strip punctuation; duplicate ids suffix `-2`.
  - link_open rule: for relative href ending `.md` (strip `#frag`), resolve `posix.normalize(join(dirname(path), href))`, map to slug; set `href=/help?doc=${slug}`; keep fragment. If target not found, leave.
  - `sanitize-html` allowlist equivalent to `apps/server/src/services/rich-text.ts` (h1-h6, p, ul, ol, li, blockquote, pre, code, table, thead, tbody, tr, th, td, a, strong, em, del, br, hr, img, span, div, sup, sub; classes `katex*`, `math*`; attrs href/src/alt/title/class/id/style? Do not allow style. Allow `span` class; `code` class language-*).
- Plain text: strip tags from HTML via `sanitizeHtml(html, {allowedTags:[], allowedAttributes:{}})`.
- Escape output as JSON string: `JSON.stringify(docs, null, 2)` inserted into TS file.
- Write header:

export function searchHelpDocs(docs, query) {
  const q = query.trim().toLowerCase();
  if (!q) return [...docs];
  return docs.filter((doc) =>
    [doc.title, doc.category, doc.plainText].some((value) => value.toLowerCase().includes(q)),
  );
}
