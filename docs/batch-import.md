# 比赛批量导入

## 目录结构

```
Alice/1/main.cpp
Alice/3/main.cpp
Bob/1/main.cpp
Bob/3/main.cpp
```

- 学生层级：默认第 1 层。
- 题目层级：默认第 2 层。
- 题目文件夹自动匹配：题目 ID → 标题（去空格/大小写）→ 比赛顺序 A/B/C/D。
- 文件夹名必须是已注册用户名，大小写敏感。
- 未注册用户跳过并在预览/报告列出。
- 非 OI 比赛、已归档比赛不能导入。
- Phase A 只支持 `.cpp/.cc/.cxx` 代码题；客观题/提交答案题的 `answers.json` 在 Phase B。

## 流程

1. 管理员在比赛控制台点“批量导入”。
2. 上传 zip，选择学生/题目层级。
3. 系统创建草稿并评测；草稿提交不会进入正式榜。
4. 预览：显示每个 `学生×题目` 的当前正式分 → 发布后分数、变化条数、未知用户、未匹配题目。
5. 选择模式并发布：
   - 覆盖：只更新批次出现的格子，即使更低
   - 合并：逐格取较高分
   - 仅补缺：只填空格
6. 发布在一个事务里写正式分、补报名、把草稿提交转正。
7. 丢弃草稿不影响正式榜。

## 名单

- CSV 第一列是用户名；支持 `username` 表头；空行忽略。
- 只追加；已参赛者跳过；未知用户名跳过并报告。
- 不自动创建账号。
- 任意时间可导入；归档后禁止。

## 隐藏参赛者

- 从正式榜（和 Phase B 订正榜）隐藏，成绩/提交保留。
- 可恢复；重新出现在榜单。
