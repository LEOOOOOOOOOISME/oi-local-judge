# OiJudge v1.1.0-rc.5

Windows x64 预发布版本，面向局域网 OI 评测与比赛：Electron 桌面端、浏览器选手/管理端、原生 Job Object 评测器。

> 这是 RC 预发布，不建议直接用于无备份的正式比赛。

## 下载

GitHub Release 附件同时提供安装器与便携包，`<version>` 与发布 tag 一致（例如 tag `v1.1.0-rc.5` 对应 `1.1.0-rc.5`）：

- `OiJudge-Setup-<version>.exe`：NSIS 安装器，支持自选安装目录，创建桌面与开始菜单快捷方式。
- `oi-local-judge-<version>-win-x64.zip`：便携版 ZIP，解压即用。

两者均内置 Node 服务、Web 前端、`ojrunner.exe`、`ojinteract.exe` 与 MinGW 运行库。安装版与便携版共用 `%APPDATA%\OiJudge` 数据目录。

## 已实现功能

### 评测

- C++14 / C++17 / C++20、C11
- OI / IOI / ACM / CF-like 排名
- 传统题、文件 IO、SPJ/testlib、交互题、客观题、输出型题
- 子任务依赖、部分分、Hack、重测
- 取消排队中 / 运行中评测：提交状态置为 `canceled`（不会变成 SE/WA），之后可重测
- 10 秒提交冷却、崩溃恢复、OLE
- Job Object 沙箱、时间/内存限制、输出限制
- 编译缓存、评测并发配置

### 比赛

- 草稿 / 运行 / 封榜 / 结束 / 归档
- 服务器时钟自动开始、封榜、解封、结束
- 参赛资格与比赛访问控制
- 团队报名模式：个人 / 团队 / 混合；团队报名、提交归属、团队榜
- 报名模式：管理员导入 / 开放报名 / 审核报名
- 报名开始 / 截止时间：开放与审核报名仅在时间窗口内可用；accepted 选手可在开赛前自助取消报名
- 审核、签到、监考视图（签到、提交数、最后提交）
- 比赛大屏：ICPC 滚榜、OI 倒计时、封榜提示
- 奖项：金/银/铜比例、并列、证书编号；可打印证书、奖项 CSV、成绩导出
- 团队奖项与团队证书：按团队榜名次授予，证书含团队名与成员数
- 全员参赛证书：个人 / 团队均可切换“包含参赛证书”，未获金银铜者标记为 participation
- 正式榜 1 秒服务端缓存（并发请求合并）与精确失效
- 比赛公告、Hack、补题/订正排名

### 出题与数据

- 题目管理、题面 Markdown/KaTeX、资源上传
- Data Plan：数据点、子任务、命名、限制
- `std` + `generator` 生成数据
- 质量门禁、预览、发布到测试点
- `std` / `generator` / validator / brute / checker 的 AI 提示词（复制式、离线）
- 题目所有权（个人 / 团队 / 系统）、可见性（public / hidden）、授权（用户/团队，read/edit）
- 题单：个人/团队/公开，题目排序与授权分享

### 团队与社区

- 创建多个常驻团队
- 队长邀请/踢人/转让、成员退出、管理员解散
- 团队题单
- 讨论区、站内消息、公告
- 用户/班级/排名/审计

### 帮助与运维

- 局域网监听、LAN 地址日志

## 已知限制

- **安装器未签名**，使用默认 Electron 图标，首次运行可能触发 SmartScreen 警告。
- **4C/8G 目标环境尚未验收**：2 小时 300 在线 + 50 并发的容量结论未完成正式测试。
- 正式榜仍是 1 秒服务端缓存 + 精确失效，不是行级增量推送；失效后的首个请求仍需全量重算。
- 证书打印未在真实浏览器中实测，打印布局与分页可能仍需调整。
- 恢复不是原子替换；失败时依赖 pre-restore 快照与 pending marker 重试。
- 部分团队/报名功能仍需浏览器手工验收。
- 备份为目录复制，不是压缩归档；大目录会同步阻塞。
- RC 版本接口与数据结构仍可能调整，升级前请备份数据目录。
