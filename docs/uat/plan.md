# OiJudge 真实用户测试（UAT）计划

> 状态：**未执行**。本文件是 v1.1.0 发布后的 UAT 协议，不得把脚本化测试当作真实用户测试。

## 目标

让真实教练/管理员和学生在干净 Windows 环境中完成完整教学闭环，找出脚本化测试发现不了的理解、流程和易用性问题。

## 参与者

最小集：

- 1 名教练/管理员
- 3 名学生

推荐：

- 2 名教师
- 5 名学生

## 环境

- 干净 Windows 10/11 x64
- NSIS 安装版
- 局域网
- 可选 TLS 与 worker 隔离
- 不使用开发机数据目录

## 场景

### 管理员/教师

1. 安装、首次启动、随机管理员密码、首次改密
2. 创建题目、上传题面/数据/附件
3. 创建比赛、导入名单、开放报名
4. 发布公告、封榜/解封
5. 批量导入学生代码、预览、发布成绩
6. 查看统计、导出分析 PDF/个人成绩
7. 创建班级、训练计划、查看学习统计
8. 备份/恢复、系统诊断
9. 可选：启用 worker 隔离并验证失败关闭
10. 可选：启用 TLS/LAN

### 学生

1. 注册/登录
2. 查看比赛、阅读题面
3. 提交代码、查看评测结果
4. 查看榜单与自己的成绩
5. 查看题目附件、题单
6. 修改密码

## 记录

- 任务是否完成
- 卡住的位置
- 不理解的术语/按钮
- 误操作与危险操作
- 截图/录屏
- 严重级别：
  - P0：无法完成核心任务/数据错误/安全问题
  - P1：核心任务需绕过，明显误导
  - P2：文案/布局/效率问题

## 通过标准

- 所有 P0 已修复
- P1 有明确修复计划
- 核心任务完成率 ≥ 90%
- 参与者能独立完成“登录 → 看题 → 提交 → 看榜”

## 处理

- P0/P1：修复后发布 `v1.1.1`
- P2：进入后续版本
- 结果写入 `docs/uat/report.md`
